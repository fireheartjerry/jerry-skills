# Rubric

Generated by `grade.py --rubric` from scenarios.json; do not edit by hand.

Scopes: `text` is every assistant message, `final` the last one, `actions` the tool calls with their inputs, `edits` the bodies of file writes and edits, `write_paths` the paths written, `all` text plus actions. A command probe runs in the run's work directory after the run and matches when it exits 0. Mechanical score = must probes matched minus failure probes matched. The independent grader scores the Musts and Failure modes below.
