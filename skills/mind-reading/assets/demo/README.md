# Fictional engineer demo

Every word in this directory was written for the demo. It contains no imported
transcript, personal model, grant, or actual project history.

The persona is an engineer who maintains a local-first issue tracker. Their
preferences are deliberately specific: reversible SQLite migrations, command
palette access for new settings, crash reproduction before a fix, and concise
verification evidence. These choices illustrate personalization; they are not
defaults imposed on someone else's model.

`demo` copies this compact model into an isolated data home and calls the same
selector used by the skill. It deliberately uses the supported legacy format,
with no index, rather than padding a fictional profile to a production model's
minimum length. The output labels this. The seed-to-prompt examples are authored
illustrations, not generated results or an accuracy benchmark.

Run the command in [the quickstart](../../references/quickstart.md). It makes no
model calls and never reads your transcript directories.
